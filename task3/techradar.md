| Категория              | Текущие технологии и методологии     | Предлагаемые изменения / новые технологии                     | Комментарии и статус                         |
|------------------------|--------------------------------------|---------------------------------------------------------------|----------------------------------------------|
| **Хранилища данных**   | MS SQL Server 2008 (монолитный DWH)  | Data Lake + DataHub (на базе современных технологий)          | Для масштабируемости и разделения доменов    |
| **BI и визуализация**  | Power BI, кастомные BI-кастомизации  | Self-service BI портал на базе semantic layer и Data Products | Упрощение создания отчётов, скорость         |

| **ИИ-сервисы**         | Python                               | Контейнеризация (Kubernetes), MLOps инструменты (MLflow)      | Ускорение доставки моделей и мониторинг      |

| **Методологии**        | Водопад, частично Agile              | Agile/Scrum, DevOps, CI/CD с автоматизацией                   | Повышение скорости выпуска и качества        |
| **Управление данными** | Отсутствует централизованный каталог | DataHub с каталогом данных, lineage, RBAC                     | Централизованное управление данными          |
