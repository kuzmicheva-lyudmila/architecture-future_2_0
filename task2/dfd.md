### Разделение на домены
| Домен                            | Основные данные                                                     | Ответственные роли                 |
|----------------------------------|---------------------------------------------------------------------|------------------------------------|
| Медицинские услуги (ClinicCare)  | Данные о пациентах, врачи, расписание, инвентарь, услуги            | Менеджер клиники, главврач         |
| ИИ-сервисы (AIMed)               | Результаты ML-инференсов, обучение моделей, выводы, рекомендации    | ML-команда, Data Scientist         |
| Финтех (FinTech)                 | Банковские счета, кредиты, транзакции, кредитные истории            | Финансовый директор, риск-менеджер |
| Персонал (HR)                    | Сотрудники, график, загрузка, обучение, кадровые метрики            | HR-менеджер                        |
| Инвентаризация (Inventory)       | Движение оборудования, расходные материалы, поставки                | Логист, закупщик                   |
| Корпоративная аналитика (CorpBI) | Интеграция доменов, метаданные, cross-domain отчёты (через DataHub) | BI-команда, архитекторы            |

### Потоки данных
| Откуда/Куда                  | Что передается                                        | Зачем / как используется                      |
|------------------------------|-------------------------------------------------------|-----------------------------------------------|
| ClinicCare      → FinTech    | Идентификаторы клиентов, статусы лечения              | Проверка риска и платежеспособности клиента   |
| FinTech         → CorpBI     | Финансовые показатели и агрегаты                      | Финансовая отчётность и кросс-доменный анализ |
| AIMed           → ClinicCare | Результаты ИИ-анализов, рекомендации                  | Поддержка врачебных решений                   |
| AIMed           → CorpBI     | Метрики моделей, эффективность                        | Аналитика качества ИИ                         |
| HR              → ClinicCare | Данные по врачам и графикам                           | Планирование расписания и загрузки персонала  |
| Inventory       → ClinicCare | Наличие оборудования и расходных материалов           | Обеспечение работы клиник                     |
| ClinicCare      → CorpBI     | Агрегированные медицинские данные (без личных данных) | Аналитика клиник                              |
| Все домены      → DataHub    | Data Products и lineage                               | Обеспечение прозрачности данных               |
